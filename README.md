# label-evidence-verifier

Evidence review only. Not a label approval or agency determination.

**Synthetic authored observations; fictional assumptions. Not legal approval or
OCR accuracy. Dirty Mode construction — runtime unverified.**

The source now composes a local, keyless demo: original geometric artwork and
authored word observations → seven conservative machine findings → escaped
JSON/HTML views → separate attributed review annotations and replay. The three
examples are software scenario designs, not executed independent pilots.

After explicit runtime activation and legitimate dependency availability
(Python 3.12+, declared Pydantic 2/setuptools), the intended journey is:

```text
labelverify demo --mode mock --out NEW_DEMO_DIRECTORY
labelverify report NEW_DEMO_DIRECTORY/DEMO-01.machine.json NEW_REVIEW.html
```

The demo creates all three scenarios, six original PNG panels, a hash manifest,
normalized source JSON, machine JSON, scenario HTML and a local index. The output
directory must not exist; its parent must exist. Partial failures are preserved:
choose another new destination rather than overwriting or resuming. Local artwork
views show full panels and original-pixel coordinates, not crops or audited pixels.
There is no OCR, image decoding, legal-source acquisition or remote provider call.

DEMO-01 is designed to support all seven fictional assumptions. DEMO-02 changes
the observed alcohol statement while retaining the application. DEMO-03 illustrates
duplicate brand, missing net evidence and invalid warning support. Expected maps
live separately under fixtures/demo and are never consumed by prediction.
No observed success is recorded here.

The genuine transport remains separate and fail-closed:

```text
labelverify check normalized-job.json machine-report.json
labelverify report machine-report.json review.html
```

All genuine rule admissions remain required. No ratified legal pack, reader,
human signature, real admission or independent custody is supplied by the demo.
Imported reports are reassessed before display; altered findings are refused.
Outputs use exclusive creation. Machine artifacts must be preserved; annotations
use a separate local SQLite file and append-only event records, never machine edits.

See [integration](docs/INTEGRATION.md), [annotation protocol](docs/DEMO-REVIEW.md)
and the [single later acceptance recipe](docs/DEMO-ACCEPTANCE.md).
All CLI/generator/database/browser/test execution is currently HELD. Licence,
independent study, legal accuracy, OCR accuracy, calibration, photo generalization,
live arms and publication remain unassessed or held. USD0; no keys needed.
