# Single later demo acceptance recipe — HELD

Synthetic authored observations; fictional assumptions; not legal approval or
OCR accuracy. Runtime unverified. This is a design, not an execution receipt.
Execute only after the owner explicitly activates runtime validation and actual
dependencies are legitimately available. No CLI, renderer, SQLite, tests, services,
browser, installation, network or unsealing was run during construction.

1. Pin actual code revision/source bytes, Python/Pydantic identities, assumption
   pack, fixture expected map, generated manifest/application/PNG bytes and command.
   Keep expected maps frozen before execution and outside prediction.
   Run once: `labelverify demo --mode mock --out NEWDIR`. Preserve any failure.
2. Compare all seven ordered findings in all three machine records against
   fixtures/demo/expected.json. DEMO-01 supports seven assumptions; DEMO-02's
   A-FORMAT supports while A-MATCH does_not_support; DEMO-03 reviews B-MATCH
   (AMBIGUOUS_LOCATION), N-MATCH (MISSING_EVIDENCE plus receipt) and W-TEXT
   (INVALID_REGION). Inspect the other four outcomes against the frozen map.
   Check proposed/tight original-coordinate provenance and all hard reasons.
   Exercise an ordinary pending/unratified real Job and verify all seven still
   review. Mutated real/demo records, wrong discriminants and altered findings
   must be refused on report/review import.
3. Inspect index/scenario HTML, local original artwork, escaped labels, machine
   text and annotations, synthetic banners and exclusions. Safe relative PNGs
   only; URI/drive/parent traversal/links/existing destinations must be refused.
   The views are full panels plus coordinates, not crops or overlays; record
   this limitation. Verify machine JSON is never overwritten by any command.
4. Using docs/DEMO-REVIEW.md's actual event schema, create an attributed event
   referencing the validated machine digest and composite revision, explicit
   actor label with identity_verified=false, expected-prior CAS and idempotency
   key. Append, export, import to a separate database, close/restart and replay.
   Verify original machine bytes/digest unchanged; duplicate import creates no
   duplicate event; stale composite revision reopens review; malformed/partial
   input leaves existing ledger data unchanged. Exercise CAS conflict and
   escaped annotation text. Supplied actor labels do not authenticate a person.
5. Reproduce into a second fresh directory; compare deterministic PNG, source,
   manifest, machine and HTML bytes. Separate actor/time metadata from deterministic
   machine artifacts. A mismatch is a failure to investigate; do not revise expected
   maps after observing outcomes. Any later source change invalidates its source pins.
